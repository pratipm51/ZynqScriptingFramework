# Zynq VHDL Logic Framework
A professional, script-first workflow for Xilinx Zynq-7000 SoC development using VHDL and C.

## Quick Start
1. Clone this repository: `git clone <url> <project_name>`
2. Follow the instructions in `FRAMEWORK_GUIDE.md` to set up your Zynq hardware.
3. Use `make` to build and `make program` to flash your board.
